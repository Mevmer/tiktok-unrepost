🎬 TikTok Unrepost

Удаляет все ваши репосты в TikTok одной кнопкой — прямо в браузере

⚡ Быстрая установка

Способ 1️⃣: Копировать букмарклет (универсальный — работает везде!)

После копирования:

  1. Откройте новую закладку (обычно Ctrl+T)
  2. Нажмите на адресную строку и создайте новую закладку (правый клик → "Добавить закладку" или звёздочка в адресной строке)
  3. Вставьте код букмарклета в поле URL (не в название!)
  4. Дайте ей название вроде "TikTok Unrepost"
  5. Сохраните
✓ Этот способ работает на всех браузерах (Chrome, Firefox, Edge, Brave) и на ПК и Android

Способ 2️⃣: Перетащить кнопку (на ПК)

Если ваш браузер поддерживает перетаскивание закладок:

🚀 Перетащи эту кнопку в панель закладок

📱 Инструкции по браузерам

🖥️

Chrome / Edge (ПК)

  1. Скопируйте букмарклет ☝️
  2. Убедитесь, что панель закладок видна (Ctrl+Shift+B)
  3. Создайте новую закладку (звёздочка в адресной строке)
  4. Вставьте код в поле URL
  5. На своём профиле нажмите закладку
🦊

Firefox (ПК)

  1. Скопируйте букмарклет ☝️
  2. Нажмите Ctrl+D на закладку
  3. Вставьте код в поле Location
  4. На своём профиле нажмите закладку
📱

Chrome (Android)

  1. Откройте эту страницу в Chrome
  2. Нажмите «Скопировать букмарклет» ☝️
  3. Откройте меню (три точки) → Закладки → Добавить закладку
  4. В поле URL вставьте код
  5. На tiktok.com нажмите закладку
🦊

Firefox (Android)

  1. Откройте эту страницу в Firefox
  2. Нажмите «Скопировать букмарклет» ☝️
  3. Нажмите на звёздочку (Добавить закладку)
  4. В поле URL вставьте код
  5. На tiktok.com нажмите закладку
🍎

Safari (iOS)

⚠️ Не поддерживается

🦁

Brave

То же самое, что Chrome — скопируйте букмарклет и добавьте новую закладку с этим кодом в URL.

🚀 Как использовать букмарклет

  1. Откройте TikTok — перейдите на свой профиль (tiktok.com/@ваше_имя)
  2. Нажмите закладку "TikTok Unrepost"
  3. Подождите — скрипт автоматически:
    • откроет вкладку "Репосты"
    • начнёт удалять репосты по одному
    • покажет прогресс в углу экрана
  4. Остановиться — нажмите кнопку "Стоп" на панели
✓ Безопасно — скрипт только нажимает кнопки, как вы бы делали вручную. Никаких данных никуда не отправляет.

⚙️ Настройки (для продвинутых)

В консоли браузера (F12 → Console) можно запустить со своими параметрами:

// Пробный запуск (ничего не нажимает, только показывает)
tiktokUnrepost.start({ dryRun: true })

// Удалить максимум 50 репостов
tiktokUnrepost.start({ limit: 50 })

// Больше времени между видео (в миллисекундах)
tiktokUnrepost.start({ delayMin: 4000, delayMax: 8000 })

// Остановить
tiktokUnrepost.stop()

❓ Часто задаваемые вопросы

Это безопасно?

Да, полностью. Букмарклет:

  • Не отправляет данные никуда
  • Не требует логин/пароль
  • Работает 100% локально в вашем браузере
  • Только нажимает кнопки на странице (как вы вручную)
  • Код открыт на GitHub — можете прочитать сами

Букмарклет синхронизируется между устройствами?

Зависит от браузера. Chrome и Firefox синхронизируют закладки автоматически, если вы авторизованы в аккаунте.

Почему скрипт работает медленно?

Между видео есть пауза 2,5–5 секунд, чтобы TikTok не ограничивал действия. Это безопасно и необходимо. Сотня репостов удаляется примерно за 7–10 минут.

Скрипт не работает. Что делать?

  1. Убедитесь, что вы на своём профиле (tiktok.com/@ваше_имя)
  2. Откройте консоль (F12 → Console) и посмотрите ошибки
  3. Создайте issue на GitHub с описанием проблемы

Как удалить букмарклет?

Нажмите на звёздочку рядом с адресной строкой → выберите букмарклет → нажмите на три точки → "Удалить".
